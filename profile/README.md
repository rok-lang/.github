<h1 align="center">Rok</h1>

<p align="center">
  A compiled language that tells you what to write.<br>
  Closed sum types, ahead-of-time compilation, a rich library,<br>
  a package registry, a REPL, and Jupyter.
</p>

<p align="center">
  <a href="https://rok-lang.org">Site</a> &middot;
  <a href="https://docs.rok-lang.org">Docs</a> &middot;
  <a href="https://rokstones.io">Registry</a>
</p>

```sh
curl -fsSL https://rok-lang.org/install.sh | sh
rok new hello && cd hello && rok run   # Hello, world!
```

## Repositories

- [**rok**](https://github.com/rok-lang/rok) - compiler, runtime, stdlib, toolchain
- [**spec**](https://github.com/rok-lang/spec) - language + stdlib spec
- [**rokstones.io**](https://github.com/rok-lang/rokstones.io) - package registry
- [**rok-lang.org**](https://github.com/rok-lang/rok-lang.org) · [**playground**](https://github.com/rok-lang/playground.rok-lang.org) - site, docs, browser
- [**rok.vim**](https://github.com/rok-lang/rok.vim) · [**rok.vscode**](https://github.com/rok-lang/rok.vscode) - editors
