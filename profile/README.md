<h1 align="center">rok</h1>

<p align="center">
  A small language with a rich library: static types, closed sum types,<br>
  ahead-of-time compilation, and a package registry, plus a REPL and Jupyter.
</p>

<p align="center">
  <a href="https://rok-lang.org">Site</a> &middot;
  <a href="https://docs.rok-lang.org">Docs</a> &middot;
  <a href="https://rokstones.io">Registry</a>
</p>

## Repositories

### Toolchain

- [rok](https://github.com/rok-lang/rok) - the compiler (`rokc`), the runtime, the standard library, and the `rok` toolchain front end.
- [spec](https://github.com/rok-lang/spec) - the language and standard-library specification (English and Korean).

### Libraries (stones)

- [http](https://github.com/rok-lang/http) - HTTP/1.1 and HTTP/2 client and server.
- [json](https://github.com/rok-lang/json) - JSON (RFC 8259) with typed encode/decode.
- [toml](https://github.com/rok-lang/toml) - TOML 1.1.0 with typed encode/decode.
- [markdown](https://github.com/rok-lang/markdown) - CommonMark + GFM to HTML.
- [rok-syntax](https://github.com/rok-lang/rok-syntax) - a tokenizer and HTML highlighter for rok and ROKON.

### Registry

- [rokstones.io](https://github.com/rok-lang/rokstones.io) - the package registry site and server.
- [rokstones.io-index](https://github.com/rok-lang/rokstones.io-index) - the registry index.

### Editors

- [rok.vim](https://github.com/rok-lang/rok.vim) - Vim and Neovim support.
- [rok.vscode](https://github.com/rok-lang/rok.vscode) - the VS Code extension.

### Web

- [rok-lang.org](https://github.com/rok-lang/rok-lang.org) - the home and documentation site.
- [playground](https://github.com/rok-lang/playground) - compile rok in the browser.

## Status

Pre-release, working toward 0.1.0.
